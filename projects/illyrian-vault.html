Illyrian Vault
Local Encrypted Password Manager

A local, offline, fully encrypted password manager for Windows: AES-256 field encryption, SQLCipher full-database encryption, and security-first features.

.NET 10 WPF Security Offline Portable

Overview

What is Illyrian Vault?

Illyrian Vault is a free, portable password manager built for Windows. Everything is stored locally in a fully encrypted database — there is no server, no sync service, and no internet requirement. The master password never leaves your device. Built with a security-first design and a clean, modern UI.

Features

Security & Functionality

  • AES-256-GCM field-level encryption on every password entry
  • SQLCipher full-database encryption — database unreadable without master password
  • PBKDF2-SHA512 key derivation at 600,000 iterations
  • Password Generator with configurable options and live strength scoring
  • HaveIBeenPwned breach check via k-anonymity
  • Clipboard Guard — auto-wipes copied secrets after 15s
  • Recovery Key — reset master password without losing data
  • Portable — single EXE, no installer or registry writes

Security Architecture

Implementation Details

Illyrian Vault applies layered cryptography: PBKDF2-SHA512 for master key derivation (600k iterations), SQLCipher for full-database AES-256 encryption, and AES-256-GCM for field-level values. The app uses exponential backoff and lockout protections, pinned memory buffers, and careful zeroing of sensitive data.
