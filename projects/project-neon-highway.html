Neon Highway
Competition Game

A 2D top-down infinite racer built with Java Swing for a programming competition at college. Completed in 10 days with full gameplay mechanics, shop system, leaderboard, and settings.

Java Java Swing Game Dev 2D Graphics Competition

Overview

About the Project

Neon Highway is a fast-paced 2D top-down infinite racer developed for a college programming competition (FSHN) within a tight 10-day deadline. Built entirely with Java Swing, this project demonstrates my ability to create engaging interactive experiences with real-time graphics, collision detection, and complex game mechanics.

The game immerses players in a neon-themed highway environment where they navigate an endless road, collecting coins and avoiding obstacles. Beyond core gameplay, the project features a comprehensive shop system for cosmetic upgrades, a persistent leaderboard tracking top 10 scores, and a settings panel for customization. This competition entry showcases game development fundamentals, event handling, real-time rendering, and performance optimization under pressure.

The game is available in two formats: as a standalone executable (.exe) for easy distribution, and as a JAR file for users with Java 17 installed. Both versions deliver the complete gaming experience with identical features and performance.

Features

What It Includes

  • Infinite Racing Gameplay — Navigate a continuously generated neon highway with smooth controls
  • Real-time Collision Detection — Accurate obstacle avoidance and coin collection mechanics
  • Dynamic Coin Collection — Earn coins throughout gameplay for cosmetic purchases
  • Comprehensive Shop System — Customize your car and map skins with collected coins
  • Global Leaderboard — Firebase integration displaying top 10 players with highest scores
  • Advanced Settings Panel — Fullscreen mode toggle, background music control, SFX toggle
  • Polished Audio Design — Dynamic background music and sound effects with independent controls
  • Performant 2D Graphics Rendering — Smooth 60 FPS gameplay with optimized sprite drawing
  • Multiple Distribution Formats — Available as standalone EXE and Java-based JAR executable

Competition Constraints

10-Day Development Challenge

This project was developed under significant time constraints as part of a college programming competition. Within just 10 days, the entire game was conceived, designed, implemented, tested, and refined. This accelerated timeline required careful planning, prioritization of core mechanics, and efficient use of Java Swing's built-in capabilities.

The compressed schedule made it crucial to focus on polishing the most impactful features: smooth gameplay, responsive controls, and an intuitive user interface. Despite the tight deadline, the final product includes not only the core racing mechanics but also the shop system, leaderboard integration, and customizable settings — demonstrating strong project management and development velocity.
